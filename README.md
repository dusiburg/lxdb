# LXDB

**LXDB** is a service built with **Next.js** (frontend) and **Go** (backend) for managing official documents of two virtual countries: the **Duspean Republic** and the **Country of Reality**.
It uses **Postgres** for database storage and **Minio** for file storage.
Documents of the Duspean Republic are parsed from the site of the [Federal Government of the Duspean Republic](https://id.dusiburg.ru/).
